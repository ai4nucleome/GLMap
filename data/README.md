# data/

Metadata and manifests for GLMap. This directory holds small,
version-controlled files only. **The large raw benchmark corpora should download as described below.**

## Committed contents

```
data/
├── audits/                 Model audit (machine-readable)
│   └── models.json         123-model registry: hf_id, family, branch (AR/MLM),
│                           param_count, context_tokens, tokenizer_type, ...
│                           Consumed by glmap.load_audit() / specs_from_audit().
│
└── downstream_tasks/       Downstream-task manifest (no vendored benchmark code)
    ├── downstream_tasks.json   6 binary tasks: description, upstream URLs,
    │                           n_train / n_test, label balance (48,439 samples)
    └── README.md               How to obtain the raw task CSVs
```

`models.json` is regenerated by `scripts/audits/models.py`; the panel
build config lives at `scripts/panel_build/panel_sources.yaml` (next to
the build code).

## Raw benchmark data

GLMap draws its 10,000-probe panel from three published genomic
benchmarks. None of the raw data is shipped in this repository; 
download what you need into `data/` before running the corresponding pipeline.

### 1. GUE — panel: promoter, splice, fungi, yeast, virus (~5,600 probes)

- **Source**: DNABERT-2 (Zhou et al., ICLR 2024) — Apache-2.0
- **Download**: <https://drive.google.com/file/d/1uOrwlf07qGQuruXqGXWMpPn8avBoW7T->
- **Extract to**: `data/GUE/`

### 2. PGB — panel: chromatin, polyA, lncRNA, nascent RNA, plant splicing (~1,600 probes)

- **Source**: Plant Genomic Benchmark / AgroNT (Mendoza-Revilla et al., 2024) — **CC-BY-NC-SA-4.0**
- **Download**: <https://huggingface.co/datasets/InstaDeepAI/plant-genomic-benchmark>
- **Extract to**: `data/PGB/`

### 3. DNA Foundation Benchmark (DFB) — panel: enhancer (1,400 probes) + downstream: 6 tasks

- **Source**: Feng et al., 2025 — Apache-2.0
- **Download**: <https://huggingface.co/datasets/hfeng3/dna_foundation_benchmark_dataset>
- **Extract to**: `data/dna_foundation_benchmark/`

The exact per-file paths consumed by the panel build are listed in
`scripts/panel_build/panel_sources.yaml`. The downstream-task layout is
documented in `data/downstream_tasks/README.md`.
